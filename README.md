# Amazon Best-Selling Books Analysis

A pandas + Streamlit + Plotly dashboard exploring the Amazon Top 50
Bestselling Books dataset (2009–2019): pricing trends, genre distribution,
author frequency, and the relationship between ratings and review counts.

## Dataset

`data/raw/amazon_books.csv` ships with a **synthetic placeholder dataset**
(same schema as the real one) so the pipeline runs out of the box:

| Column | Type | Notes |
|---|---|---|
| Name | string | book title |
| Author | string | |
| User Rating | float | 0.0–5.0 |
| Reviews | int | review count |
| Price | float | USD |
| Year | int | year on the bestseller list |
| Genre | string | Fiction / Non Fiction |

To use the real Kaggle dataset ("Amazon Top 50 Bestselling Books
2009–2019"), download it and overwrite `data/raw/amazon_books.csv` with the
same column names, then re-run the pipeline.

## Setup

```bash
pip install -r requirements.txt
```

## Run the pipeline

```bash
python pipeline/clean_data.py
```

This reads `data/raw/amazon_books.csv`, cleans it, adds derived columns
(`price_bucket`, `decade`), and writes `data/processed/books_clean.csv`.

## Run the dashboard

```bash
streamlit run app/main.py
```

## Run the tests

```bash
pytest
```

## Swapping in a different dataset

1. Replace `data/raw/amazon_books.csv`, keeping the same column names
   (`Name`, `Author`, `User Rating`, `Reviews`, `Price`, `Year`, `Genre`) —
   or update `REQUIRED_COLUMNS` in `pipeline/clean_data.py` if your columns
   differ.
2. Re-run `python pipeline/clean_data.py`.
3. Re-run `streamlit run app/main.py` — nothing is hardcoded, so the
   dashboard reflects the new data automatically.
